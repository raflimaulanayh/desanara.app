# Visi & Masalah

## Masalah

- UMKM desa kesulitan memperkenalkan produknya ke masyarakat luas.
- Masyarakat (wisatawan, pencari oleh-oleh, reseller, pemda/CSR) kesulitan menemukan produk khas dari desa tertentu.
- Banyak UMKM belum melek digital: foto produk, deskripsi, harga, dan legalitas belum siap.

## Solusi

1. **Platform katalog multi-desa.** Tiap desa punya halaman dan admin sendiri (desa = tenant), plus pencarian lintas desa.
   Pembeli memesan langsung ke penjual lewat WhatsApp.
2. **Program edukasi UMKM.** Foto produk dengan HP, menulis deskripsi dan menentukan harga, WhatsApp Business,
   cara memakai platform, dan legalitas (NIB lewat OSS, PIRT, halal _self-declare_).

## Siapa penggunanya

| Persona                    | Kebutuhan utama                                                 |
| -------------------------- | --------------------------------------------------------------- |
| Pembeli / wisatawan        | Menemukan produk khas desa dan menghubungi penjual dengan mudah |
| Pemilik UMKM               | Toko online sederhana tanpa ribet; bisa dibantu pendamping      |
| Pendamping (mahasiswa/KKN) | Menginput dan merawat data UMKM atas nama pemilik               |
| Admin desa / BUMDes        | Memverifikasi UMKM desanya dan melihat dampaknya                |
| Super admin (HIMA)         | Mengelola desa, kategori, dan pengguna                          |

## Ukuran keberhasilan (MVP, 11 Desember 2026)

- Platform live di domain sendiri, dua bahasa (ID/EN), dipakai di seminar desa pilot.
- Minimal 15–30 UMKM desa pilot tampil (sementara memakai data demo).
- Statistik view dan klik WhatsApp per UMKM tersedia untuk laporan dampak.
- Pre-test dan post-test edukasi menunjukkan peningkatan pemahaman.
