# Checklist serah-terima pengurus (setiap pergantian periode HIMA)

## Akses & aset (semua atas nama organisasi, bukan pribadi)

- [ ] GitHub organization HIMA: pengurus baru jadi owner, pengurus lama dikeluarkan/diturunkan
- [ ] Domain: akun registrar, tanggal perpanjangan, siapa yang membayar
- [ ] Vercel team, Supabase organization, Cloudflare account (R2 + DNS): owner dipindahkan
- [ ] Akses SSH VPS (kampus/sewa): kunci lama dicabut, kunci baru ditambahkan
- [ ] Password manager/vault bersama berisi secret production (bukan di chat)
- [ ] Nomor WhatsApp yang dipakai untuk demo/admin

## Pengetahuan

- [ ] Baca `AGENTS.md`, `docs/README.md`, semua ADR
- [ ] Walkthrough setup lokal sampai `bun run check:all` hijau di laptop pengurus baru
- [ ] Simulasi deploy dan restore backup database (dari R2) di environment dev
- [ ] Daftar kontak: admin tiap desa, IT kampus, dosen pembina

## Kondisi project

- [ ] `docs/product/features-mvp.md` dan `roadmap.md` diperbarui
- [ ] Plan yang masih berjalan di `docs/plan/` statusnya jelas
- [ ] Entri CHANGELOG "Serah-terima periode <tahun>" ditulis
- [ ] Tagihan berjalan (domain, Supabase, VPS, Vercel) dan sumber dananya
