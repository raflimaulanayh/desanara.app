# Internationalisation

- Locales: `id` (default) and `en` — `packages/i18n/src/index.ts`.
- `apps/web`: next-intl with `localePrefix: 'as-needed'` → Indonesian has no prefix (`/desa/baros`), English uses `/en/desa/baros`. Locale negotiation in `src/proxy.ts`.
  Call `setRequestLocale(locale)` in every layout/page so pages stay static.
- Messages: shared in `packages/i18n/messages/{id,en}.json` (namespace `common`), app-specific in
  `apps/<app>/messages/{id,en}.json`. Both locales must have the same keys.
- `apps/dashboard`: Indonesian only for the MVP, but all copy goes through next-intl (`src/i18n.ts`) so EN can be added.
- URL segments are Indonesian for all locales (ADR 0008: `/jelajah`, `/desa/[village]`, `/produk/[product]`, `/tentang`; route folders use Indonesian names, params and code stay English). Old English URLs redirect (308) via `next.config.ts`; content slugs stay in Indonesian.
- User content (products, businesses) is written in Indonesian; English comes from `*_translations` when present,
  falling back to Indonesian. Machine translation is a phase-2 feature.
- Prices are always IDR (`formatRupiah`), formatted with the UI locale.
- SEO: `alternates.languages` per page; `<html lang>` follows the locale.
